# OpenSourceLens — Feature Specifications

OpenSourceLens organizes its analytical capabilities into six core modules designed to uncover the health, activity patterns, and community dynamics of **any eligible public GitHub repository**.

---

## 1. Dynamic Ingestion & Repository Validator

The entry point for the platform is an interactive on-demand ingestion engine:

- **Repository Validation:**
  - Accepts GitHub repository URLs (e.g., `https://github.com/fastapi/fastapi`) or shorthand identifiers (`owner/repo`).
  - Verifies public accessibility, repository existence, and primary branch status via GitHub REST API v3.
  - Checks eligibility thresholds (e.g. minimum number of historical commits/issues to prevent empty repositories from skewing statistical models).
- **Rate-Budgeted Asynchronous Ingestion:**
  - Calculates GitHub API rate limit budgets and schedules tiered data collection.
  - Fetches repository metadata, recent commit activity, contributors list, pull requests, issues, labels, and release milestones.
  - Exposes real-time ingestion progress telemetry (percentage complete, entities harvested, estimated time remaining).
- **Relational Persistence:**
  - Stores cleaned repository entities into relational database tables with foreign-key relationships.
  - Caches pre-computed analytics snapshots to enable instant re-visits without re-crawling.

---

## 2. Development Activity Intelligence

Analyzes the pace, consistency, and evolutionary trajectory of development over time:

- **Commit Velocity & Rolling Trends:**
  - Weekly and monthly commit frequency time-series charts.
  - Moving-average trendlines capturing whether code contribution is accelerating, plateauing, or slowing down.
- **Activity Consistency & Seasonality:**
  - Quantifies development consistency scores (identifying regular sprint cadences vs. sporadic bursty commits).
  - Day-of-week and hour-of-day commit heatmaps highlighting team working schedules and timezone distributions.
- **Anomaly & Change-Point Detection:**
  - Statistical outlier detection identifying sudden drops in development (e.g. key contributor departures) or sharp spikes (e.g. major release sprints).
- **Release Cadence & Versioning Health:**
  - Frequency of minor/major releases over time and interval consistency between official tags.

---

## 3. Contributor Ecosystem Intelligence

Examines the human infrastructure, community dynamics, and sustainability of the project:

- **Contribution Concentration (Gini Coefficient & Bus Factor):**
  - Calculates Gini coefficient and Lorenz curves of commit and review distributions across authors.
  - Identifies project fragility (e.g. a high Gini coefficient $\ge 0.85$ indicates extreme reliance on 1–2 key maintainers, signaling high "bus factor" risk).
- **Contributor Retention & Cohort Analysis:**
  - Tracks monthly/quarterly newcomer cohorts over time.
  - Measures contributor retention rates: what percentage of first-time committers return to submit subsequent contributions within 30, 90, and 180 days.
- **Community Segmentation (Core vs. Regular vs. Casual):**
  - Clusters contributors into distinct tiers based on contribution volume, longevity, and activity frequency.
  - Newcomer onboarding velocity: time elapsed from first issue/PR to first merged commit.

---

## 4. Pull Request Intelligence

Analyzes the code review pipeline, maintainer responsiveness, and integration efficiency:

- **Review & Merge Latency Distributions:**
  - Time-to-first-response (TTFR) by maintainers on community PRs.
  - Continuous time-to-merge distribution with non-parametric percentiles ($P25$, Median $P50$, $P75$) and interquartile range (IQR).
- **PR Lifecycle & Merge Rate Analytics:**
  - Ratio of PRs merged vs. closed without merge vs. currently stale/open.
  - Survival analysis (Kaplan-Meier estimator) tracking the probability of an open PR remaining unreviewed after $t$ days.
- **Review Bottleneck Detection:**
  - Flags PR backlog accumulation and identifies whether delays stem from review starvation (lack of reviewer bandwidth) or protracted revision cycles.

---

## 5. Issue Intelligence & NLP Diagnostics

Leverages machine learning, deep learning, and vector embeddings to structure issue backlogs:

- **Supervised Issue Classification (Fine-Tuned DistilBERT vs. Classical ML):**
  - Classifies issue titles and descriptions into canonical functional categories: `bug`, `feature`, `documentation`, `question`, and `other`.
  - Evaluates both a fine-tuned DistilBERT transformer (66.9M parameters) and classical TF-IDF + Logistic Regression / Linear SVM baselines.
  - Displays real-time softmax probability distributions and confidence scores.
- **Dense Semantic Duplicate & Related Issue Retrieval:**
  - Transforms issue text into 384-dimensional dense sentence embeddings using Sentence-Transformers (`all-MiniLM-L6-v2`).
  - Computes cosine similarity across historical repository issues to retrieve top-K similar reports, preventing duplicate discussion fragmentation.
  - Includes an interactive similarity threshold filter ($0.20$ to $0.85$).
- **Resolution Velocity Advisory & Aging Horizons:**
  - Estimates resolution velocity speed tiers (`< 1 Day`, `1-7 Days`, `7-30 Days`, `30+ Days`) using an ensemble 100-tree Random Forest trained on creation-time characteristics (structural text length, code snippets, author association, label counts).
  - Provides conservative error boundaries and empirical advisory notices.
  - Backlog aging analysis: age distribution of currently open unresolved issues.

---

## 6. Repository-Level Intelligence & Findings Report

Synthesizes findings across development, contributor, PR, and issue domains into an automated repository intelligence dossier:

- **Executive Project Dossier:**
  - High-level summary cards: Project Velocity Tier, Community Decentralization Index, Review Responsiveness Grade, and Triage Efficiency.
- **Evidence-Backed Automated Findings:**
  - Rule-based and heuristic synthesis highlighting project strengths (e.g., "Highly active community with 82% 30-day PR merge rate") and project risks (e.g., "High contributor concentration: 91% of commits authored by 2 developers").
- **Interactive Single-Repository Workspace:**
  - Tabbed interface allowing users to seamlessly transition between Overview, Activity, Contributors, Pull Requests, Issues, and AI Intelligence views.
