# OpenSourceLens — Project Features

## 1. Repository Overview

OpenSourceLens will provide a high-level overview of a selected GitHub repository.

The repository overview will include:

- Repository information
- Total number of issues
- Open and closed issue counts
- Issue activity
- Issue labels and categories
- Issue creation trends
- Issue closure trends
- Basic repository statistics

---

## 2. Issue Analytics

The platform will analyze repository issues to identify important patterns and trends.

The analysis will include:

- Issue category distribution
- Open vs. closed issue distribution
- Issue trends over time
- Label distribution
- Issue resolution-time distribution
- Repository activity patterns
- Comparison of issue characteristics where applicable

This component forms the main data analytics and exploratory data analysis part of the project.

---

## 3. AI-Based Issue Classification

OpenSourceLens will automatically classify GitHub issues into meaningful categories using natural language processing and machine learning.

The initial categories will be:

- Bug
- Feature Request
- Documentation
- Question
- Enhancement
- Other

The project will compare two approaches:

### Classical Machine Learning

A traditional NLP pipeline will be developed using techniques such as:

- Text preprocessing
- TF-IDF feature extraction
- Logistic Regression and/or Support Vector Machine

### Transformer-Based Approach

A pretrained transformer model will be fine-tuned for issue classification.

A model such as DistilBERT or BERT will be evaluated depending on dataset size, computational requirements, and experimental results.

The performance of the classical and transformer-based approaches will be compared using appropriate evaluation metrics.

---
