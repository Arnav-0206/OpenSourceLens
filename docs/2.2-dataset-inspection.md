## 7. Key Findings & Directives for Subsequent Steps

1. **Text Cleaning (Step 2.3):**
   - **57.33%** of issues contain code blocks and **18.08%** contain HTML comments. Dedicated cleaning functions must strip template comments and normalize code snippets.
2. **Timestamp Cleaning (Step 2.4):**
   - `created_at` and `updated_at` are 100% populated. `closed_at` is only populated on closed issues (1,200), with 0 missing closed timestamps on closed issues.
3. **Missing Value Handling (Step 2.5):**
   - Only **10 issues (0.42%)** have empty bodies. Impute empty bodies using the `title` text.
4. **Duplicate & Irrelevant Data (Step 2.6):**
   - Global IDs and composite keys are 100% unique. Exact title/body pairs (8) will be inspected for automated bots/spam.
5. **Label Normalization (Step 2.7):**
   - **17.04%** of issues are unlabeled. Label hierarchy mapping is essential to consolidate `bug`, `kind/bug`, and `type: bug` into uniform classes.
